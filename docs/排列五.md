# 排列五分析规则

## 五位独立分析

万位、千位、百位、十位、个位分别研究号码频率、冷热、遗漏、位置轮动、重号、邻号及 012 路。整体组合可辅助观察奇偶、大小和数字分布，但不能取代逐位筛选。

## 与排列三的联动硬规则

1. 先完成排列三选号。
2. 再以排列三号码作为排列五前三位。
3. 排列五前三位必须与排列三号码逐位完全一致。
4. 仅对排列五后两位进行独立筛选。
5. 输出前再次逐位校验；前三位不一致，方案不得发布。

例如，若排列三为 `572`，则排列五只能以 `572` 开头，后两位另行分析。

## 号码池

- 用户提供排列五五个位置号码池时，五位必须分别从对应池中选择。
- 用户只提供排列三位置号码池时，排列五前三位由排列三结果继承，后两位独立分析。
- 不得选择任何对应位置号码池之外的数字。

## 输出格式

默认输出一注排列五，并标注前三位与排列三联动校验结果及后两位筛选依据。
