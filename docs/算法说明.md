# 算法说明

## 统计层
- 位置频数：在选定近期窗口内统计各数字出现次数。
- 遗漏值：从最新一期向历史回看，计算某数字最近一次出现的期距。
- 结构指标：适用于数字型玩法，计算和值、跨度、奇偶、大小、012路。
- 多号码区（大乐透前后区、双色球红蓝球）分别统计。

## 候选层
当前候选器按每个位置的近期出现频数排序。并列时优先较小数字。组合只取各位置排名靠前的数字，保持方法透明、可复现。

这是一种描述性启发式筛选，不是经统计验证的预测模型。频数高不代表下一期更容易出现；遗漏长也不代表必然回补。项目不输出虚构命中率。

## 偏差检测

目标：用数据实证回答“这段开奖样本是不是真均匀”，不参与选号，不预测下一期。

### 卡方拟合优度检验
- 对每个位置，把各数字出现次数与均匀期望（总次数 ÷ 数字个数）比较。
- 统计量：χ² = Σ(O−E)²/E，自由度 df = 数字个数 − 1。
- p 值：P(χ²_df ≥ 观测值)，用正则化不完全伽马函数计算（标准库 math 实现，无外部依赖）。
- 解读：p < 0.05 标“偏离均匀”，否则“与均匀一致”。期望频数小于 5 时卡方近似仅供参考。
- 多号码区（大乐透前后区、双色球红蓝球）按区整体检验，序列为各期号码展平后的顺序。

### 游程检验（Wald-Wolfowitz）
- 把该位置序列按奇/偶二值化，数游程 R（连续相同值的一段为一个游程）。
- 期望 E[R] = 2n₁n₀/n + 1，方差 Var(R) = 2n₁n₀(2n₁n₀ − n₁ − n₀) / (n²(n−1))，Z = (R − E[R]) / √Var(R)，双尾 p 值由正态近似给出。
- 解读：p < 0.05 说明奇偶排列顺序与随机排列显著不同，标“游程异常”。
- 奇偶只有一种时检验不适用。

### 解读口径
- 多位置同时检验存在多重比较问题：各位置 p 值分别报告，不合成为一个总 p 值；位置越多，偶然出现一个 p < 0.05 的概率越高。
- 显著偏离只说明这段样本里不均匀，不等于能预测下一期；不显著也不证明绝对均匀。

## 后续可升级
1. 加入滚动窗口对比（20/50/100/300/500期）。
2. 加入相似走势检索与模式聚类。
3. 将传统易数规则作为独立解释层，保留每条规则的来源、参数和推演过程。
4. 接入经核验的官方数据源，记录抓取时间、来源与数据校验结果。
5. 进行时间顺序严格的样本外评估，避免数据泄漏。
