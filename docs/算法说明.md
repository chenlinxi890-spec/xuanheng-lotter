# 算法说明

## 统计层
- 位置频数：在选定近期窗口内统计各数字出现次数。
- 遗漏值：从最新一期向历史回看，计算某数字最近一次出现的期距。
- 结构指标：适用于数字型玩法，计算和值、跨度、奇偶、大小、012路。
- 多号码区（大乐透前后区、双色球红蓝球）分别统计。

## 候选层
当前候选器按每个位置的近期出现频数排序。并列时优先较小数字。组合只取各位置排名靠前的数字，保持方法透明、可复现。

这是一种描述性启发式筛选，不是经统计验证的预测模型。频数高不代表下一期更容易出现；遗漏长也不代表必然回补。项目不输出虚构命中率。

## 后续可升级
1. 加入滚动窗口对比（20/50/100/300/500期）。
2. 加入相似走势检索与模式聚类。
3. 将传统易数规则作为独立解释层，保留每条规则的来源、参数和推演过程。
4. 接入经核验的官方数据源，记录抓取时间、来源与数据校验结果。
5. 进行时间顺序严格的样本外评估，避免数据泄漏。
