# 排列三分析规则

## 分析维度

1. **位置分析**：百位、十位、个位分别统计频率、遗漏、冷热变化及位置轮动。
2. **跨期关系**：观察重号、邻号、隔期重复，以及连续 3—5 期结构变化。
3. **形态分析**：判断组六、组三、豹子的样本分布与近期变化，不固定追某一形态。
4. **和值与跨度**：结合近期分布选择观察区间，不将中区或小跨度当作必然规律。
5. **奇偶与大小**：观察 2 奇 1 偶、2 偶 1 奇，以及两大一小、两小一大等组合的样本变化。
6. **012 路**：逐位按除以 3 的余数分类，观察路数分布及位置差异。
7. **冷热与遗漏**：用于描述历史状态，不把遗漏期数解释为回补概率上升。

## 筛选顺序

- 核对最新期号及开奖数据；
- 建立各位置候选集合；
- 按用户给定号码池剔除池外数字；
- 结合用户当期方向与历史结构缩小候选；
- 检查形态、和值、跨度及位置关系；
- 形成最终直选号码并复算所有指标。

## 输出格式

默认一注直选，附简要指标：号码、形态、和值、跨度、奇偶、大小、012 路及主要筛选依据。只在用户明确要求时提供多注、主备方案或胆码。
