# 玄衡 · 易数数字彩分析系统

玄衡是一套面向数字型彩票的分析规则与选号流程文档，以统计特征为主、易数思路为辅助。先研究历史数据，再逐位筛选，不把趋势推测包装成确定性结论。

## 当前规则范围

- **排列三**：百位、十位、个位独立分析，结合奇偶、大小、和值、跨度、012路、冷热、遗漏、重号、邻号及组三/组六形态。
- **排列五**：五个位置独立分析，并与排列三建立前三位联动约束。
- **默认输出**：同时要求两种玩法时，默认排列三直选一注、排列五直选一注；排列五前三位必须与排列三完全一致。

大乐透、双色球、七星彩属于后续扩展方向；本仓库当前文档不代表这些玩法已实现完整分析流程。

## 工作流程

1. 核对期号、开奖数据及数据覆盖范围。
2. 数据完整时研究近 500 期结构。
3. 分位置分析热冷、遗漏、轮动、重号、邻号和 012 路。
4. 综合和值、跨度、奇偶、大小及组三/组六形态。
5. 按各位置近期出现频数排序，逐位生成候选。
6. 先确定排列三，再生成排列五并校验前三位一致。
7. 输出可复核指标；数据不足时明确说明。

## 重要说明

彩票开奖结果具有随机性。历史频率、遗漏、冷热、形态或易数分析均不能保证预测准确，也不会使某个号码因长期未开出而必然更容易出现。请将分析视为研究与娱乐，不作为收益承诺或投注依据。

当前仓库以规则文档为主，不包含已验证的自动开奖采集服务、完整统计程序或可保证命中的预测模型。只有在代码、数据来源和测试结果实际提交后，相关功能才会标记为已实现。
